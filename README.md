# SMS and Email Fraud Detection System

A machine learning project designed to classify potentially fraudulent SMS messages and emails using text-based classification techniques.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

## Project Features
- Text preprocessing and feature extraction
- Automated message classification
- Evaluation using machine learning performance metrics

## Installation and Usage

**1. Clone the repository**
```bash
git clone https://github.com/Ananway2008/sms-email-fraud-detection.git
```

**2. Navigate to the project folder**
```bash
cd sms-email-fraud-detection
```

**3. Install dependencies**
```bash
pip install pandas numpy scikit-learn
```

**4. Run the program**
```bash
python "sms and email fraud detection 2.py"
```

## Model Evaluation

Performance metrics such as accuracy, precision, recall, F1-score, and the confusion matrix should be reported using validated test results.

## Limitations

Predictions depend on the quality and representativeness of the training data. The model should not be treated as a guarantee that a message is safe or fraudulent.
